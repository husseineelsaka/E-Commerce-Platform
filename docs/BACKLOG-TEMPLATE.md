# Backlog story template

## Story: short capability

**Layer:** L1–L6  
**Owner:** team member  
**Estimate:** at most 4 hours; split a larger story before scheduling.

As a <user>, I want <capability> so that <value>.

**Definition of Done:** A named automated test or observable command proves the behavior, documentation reflects it, and a teammate reviews the PR. Record the actual test or command and result here.

The team backlog has 12–15 stories, covers each layer L1–L6, and assigns the first L1 owners.
